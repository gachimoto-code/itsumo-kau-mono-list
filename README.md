# いつも買うものリスト

いつも買うものの最安値・直近価格・価格履歴を記録するリストです。GitHub Pages で公開しています。

## 構成

- `index.html` — 一覧アプリ本体（検索・カテゴリ絞り込み・価格履歴グラフ）
- `data.json` — 商品と価格記録のデータ

## データについて

- 元データは Muse の「いつも買うものリスト」で管理しており、このリポジトリの `data.json` はその公開用コピーです。
- ページ上の「商品を追加」「価格を追加」などの編集は、開いたブラウザの localStorage にだけ保存されます（他の端末・他の人には反映されません）。
